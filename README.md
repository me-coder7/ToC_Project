# Interactive Simulation Studio

This package is already arranged as a static multi-project website.

## Included apps
- `/toc/` — Theory of Computation Workbench
- `/payment/` — Smart Payment Card Validator

## Hosting
Because this package is already prebuilt and static, you can host it directly on platforms such as Vercel, Netlify, or GitHub Pages without merging the codebases again.

## Project switching
- Landing page: `/`
- Workbench home button: `Projects`
- Validator home button: `Projects`

## Local check
Open `index.html` with a static server if you want to preview locally.
